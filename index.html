BIRINCHI MARTA ULASH (WINDOWS · uDMX)

Eng oson yoʻl — SAHNA NURI Bridge: chapdagi YUKLAB OLISH (.exe) → faylni bir marta ishga tushiring (Windows „Неизвестный издатель“ desa: Подробнее → Выполнить в любом случае) → BRIDGE ULASH. Zadig kerak emas, quyidagi qadamlar faqat Bridge’siz ulash uchun.

  1. FreeStyler’ni yoping. Bir vaqtda faqat bitta dastur kabeldan foydalana oladi.
  2. Dasturni Chrome yoki Edge’da oching.
  3. uDMX ULASH → roʻyxatda „uDMX“ → Подключить / Ulash.
  4. Roʻyxat boʻsh boʻlsa yoki xato chiqsa: drayverni WinUSB’ga almashtiring.
    1. zadig.akeo.ie dan Zadig’ni yuklab oling va oching.
    2. Options → List All Devices → roʻyxatdan uDMX.
    3. Oʻng tomonda WinUSB → Replace Driver.
    4. Brauzerni qayta oching va 3-qadamni takrorlang.

FreeStyler’ga qaytish kerak boʻlsa, Zadig’da drayverni yana libusbK’ga almashtirasiz.

💻 Kompyuter Windows · Chrome yoki Edge

  1. Manzil satrining oʻng tomonidagi ⊕ Oʻrnatish belgisini bosing (yoki ⋮ menyu → Ilovani oʻrnatish).
  2. Oʻrnatish ni tasdiqlang.
  3. Ish stoli va Пуск menyusida SAHNA NURI belgisi paydo boʻladi.

📱 Android Chrome

  1. Oʻng yuqoridagi ⋮ menyuni oching.
  2. Ilovani oʻrnatish yoki Bosh ekranga qoʻshish ni bosing.
  3. Bosh ekranda SAHNA NURI belgisi paydo boʻladi.

📱 iPhone / iPad Safari

  1. Pastdagi Ulashish ⬆ tugmasini bosing.
  2. Bosh ekranga (На экран «Домой») ni tanlang.
  3. Oʻng yuqorida Qoʻshish ni bosing.
